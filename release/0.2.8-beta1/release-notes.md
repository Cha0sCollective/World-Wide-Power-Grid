0.2.8-beta1 speeds up wire processing and saved-circuit restoration, with the retained improvements enabled by default. Extension API 1.0.0 stays unchanged.

- Batch PG and CEE wires and spread saved-wire restoration across bounded work windows.
- Reduce repeated loading calculations and retain native numerical safeguards on Windows and Linux.
- Add regression fixtures for twelve logic, memory, supply and heater circuits.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.265, Java 21, Create 6.0.10, CEE 1.1.4, Power Grid 0.6.2 and Architectury 13.0.11. Set PG multiTicks to 16. Match server and client mod versions.
