An alpha for testing safer circuit loading and the expanded add-on SDK. Large-network performance remains under investigation.

- Avoids deep wire-tracing recursion and reduces repeated graph, matrix and measurement work.
- Preserves stored energy and marks readings unavailable while affected circuits load; fixes a single-player buzzer crash.
- Includes the build-your-add-on tutorial, adjustable-load starter, updated reference and troubleshooting guides; API 1.0.0 stays compatible.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.231 or 21.1.248, Java 21, Create 6.0.10-280, CEE 1.1.3, Power Grid 0.6.2 and Architectury 13.0.8. Match server and client mod versions.
