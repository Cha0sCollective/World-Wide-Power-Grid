# WWPG 0.2.0 downloads

The [public release](https://github.com/Cha0sCollective/World-Wide-Power-Grid/releases/tag/0.2.0)
now has five downloads. Start with **wwpg-0.2.0.jar** for ordinary play.

| File | Use |
| --- | --- |
| `wwpg-0.2.0.jar` | Install in `mods` with the pinned upstream dependencies. |
| `wwpg-0.2.0-example-worlds.zip` | Four optional saves and the two Workshop demonstration mods; read `START-HERE.md`. |
| `wwpg-0.2.0-developer-sdk.zip` | Both APIs, sources/Javadoc, Maven repository and independently buildable example projects. |
| `wwpg-0.2.0-verification.zip` | Optional original release files, test records, logs and screenshots. |
| `wwpg-0.2.0-checksums.txt` | SHA256 fingerprints for the four files above. |

This presentation replaced the original list of 29 downloads on 11 October 2026.
The verification archive preserves all 29 original files byte for byte, including
the original checksums, longer notes and accepted evidence bundle. Previous
individual 0.2.0 asset URLs are superseded by these grouped downloads. The mod jar
keeps its original name, URL and bytes. The release tag is unchanged.

The [download-layout manifest](download-layout.json) records the new outer files
and hashes. The [original distribution](distribution.json) still records the
original accepted downloads; the [verification manifest](verification.json)
still identifies the accepted runtime, APIs, worlds and evidence. Grouping files
does not extend those acceptance claims or change saved-world contents.

[Installation](../../docs/INSTALL.md) explains selecting a world and installing
the optional Workshop mods. [API instructions](../../docs/EXTENSION_API.md)
explain extracting the SDK's original Maven and source archives.
