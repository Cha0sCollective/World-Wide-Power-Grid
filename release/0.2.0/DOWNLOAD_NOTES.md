WWPG lets stationary **CEE and Power Grid** machines share power through either mod's wires. Version 0.2.0 adds **extension API 1.0** for add-on creators, an eleven-station API Workshop, and fixes for saved connections and unavailable meter readings.

## Download

**For ordinary play, download the mod jar and install the required upstream mods.**

| I want to… | Download |
| --- | --- |
| Install WWPG | [Mod jar](https://github.com/Cha0sCollective/World-Wide-Power-Grid/releases/download/0.2.0/wwpg-0.2.0.jar) |
| Try ready-built circuits | [Example worlds](https://github.com/Cha0sCollective/World-Wide-Power-Grid/releases/download/0.2.0/wwpg-0.2.0-example-worlds.zip) — Stationary Yard and API Workshop, with optional Pinout editions and Workshop add-ons |

## Install

Use **Minecraft 1.21.1, NeoForge 21.1.231, Java 21, Create 6.0.10-280, CEE 1.1.3, Power Grid 0.6.2 and Architectury 13.0.8**. Install the same versions on the server and clients. Existing beta.5 worlds remain compatible.
