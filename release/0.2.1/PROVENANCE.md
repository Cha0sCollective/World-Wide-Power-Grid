contains the exact accepted runtime, worlds, SDK and verification archive.
[Distribution](distribution.json) records the public download URLs, sizes and hashes.

The release tag identifies source commit `39df6fa087d0bbc4601d9aab40d76105895a1e7a`.
Acceptance and publication records were committed after that source was tested.
The API binaries and contract remain at 1.0.0.

The verification archive contains all locked inputs, CI reports, original 248
artifact ZIPs, SDK build results, client logs and screenshots, including the
interrupted graphical attempt and its successful fresh run. Paths beginning
with `build/` or `run/` identify retained files inside that archive; they are
not additional downloads or instructions to install test files.

Earlier releases, their tags and their captured evidence are unchanged.
