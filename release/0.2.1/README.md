# WWPG 0.2.1

This release adds NeoForge **21.1.248** support alongside **21.1.231**. The
same jar runs on both. Minecraft stays at 1.21.1 and extension API stays at 1.0.0.

The dependency declarations also allow newer NeoForge, Create, CEE and Power
Grid versions for player testing. Only the combinations listed in
[version compatibility](../../docs/VERSION_COMPATIBILITY.md) are verified.

Players should download the mod jar from the
[release page](https://github.com/Cha0sCollective/World-Wide-Power-Grid/releases/tag/0.2.1)
and follow the [installation guide](../../docs/INSTALL.md). The other four
downloads group worlds, the developer SDK, verification records and checksums.

[Dependencies](dependencies.json), [verification](verification.json),
[download hashes and sizes](download-layout.json) and [release notes](RELEASE_NOTES.md)
record the published files. Earlier releases and their evidence are unchanged.
