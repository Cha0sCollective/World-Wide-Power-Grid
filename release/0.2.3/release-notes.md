0.2.3 improves PG wire targeting on CEE equipment and keeps test fixtures out of the gameplay jar. API 1.0.0 and existing saves stay compatible.

- Connect PG wires to exposed voltage-regulator posts, stacked regulator terminals and tiny capacitor pins using their native selection bounds.
- Keep all GameTests and fixtures in a separate test companion, with gameplay code and native solver provenance retained in the mod jar.
- Preserve wire reach and obstruction rules, electrical settings, native solver binaries and all 16 substeps.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.231 or 21.1.248, Java 21, Create 6.0.10-280, CEE 1.1.3, Power Grid 0.6.2 and Architectury 13.0.8. Match server and client mod versions.
