0.2.8-beta.3 fixes large-world restoration stalls and restores Power Grid's intended generator timing and overload response.

- Avoid repeated CEE circuit scans during restoration while retaining rollback and unavailable-reading safeguards.
- Restore PG's original rotor and clutch timing, including intended self-excitation oscillation under overload.
- Retain the prior unload, circuit regrouping, measurement and native allocation safety fixes; API 1.0.0 is unchanged.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.266, Java 21, Create 6.0.10, CEE 1.1.4, Power Grid 0.6.2 and Architectury 13.0.11. Set PG multiTicks to 16. Match server and client mod versions.
