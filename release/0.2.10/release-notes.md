WWPG 0.2.10 reduces brief slowdowns on Power Grid-powered CEE trains when wire chunks reload.

- Unchanged wire segments can rejoin a live line without adding a redundant wait for chunk readiness.
- Both gauge needles stay visible during normal powered travel. A genuine outage still makes readings unavailable.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.262, Java 21, Create 6.0.10, CEE 1.1.4, Power Grid 0.6.2 and Architectury 13.0.12. Set PG multiTicks to 16. Match server and client mod versions.
