Beta.4 includes matrix ownership, unload/native safety, circuit regrouping and
handheld connector fixes. API 1.0.0, saves, equations and all sixteen substeps
remain compatible. The frozen release source is
`a0f2a0fb3f20190978721aa9f0a9eafc97e778dc`; its jar matches tested dev.94
in every entry except the version declaration.

Acceptance retains dev.94's Windows Pinout yard on both solvers, with original
cold restarts, exact archive reopens, graphical controls and two real clients.
The combined yard includes the ordinary exhibits; separate BASE yard runs and
downloads are retired. Runtime and API Workshop BASE/PINOUT installations remain
separate.

The [original matrix](https://github.com/Cha0sCollective/World-Wide-Power-Grid/actions/runs/38976361322)
retains four passing Java jobs and successful Native prefixes. Its Native
reference fixture failed after GameTest removed wires but left source blocks
ticking. A control-only teardown repair leaves measured traces, guards and the
player jar unchanged. The [Native continuation](https://github.com/Cha0sCollective/World-Wide-Power-Grid/actions/runs/38981121595)
passed all four Windows/Linux jobs, preserving the failed artifacts and original
prefix outcomes. The manifest records this assembled coverage without calling
the failed workflow a passing run.

Both exact API Workshop archives passed three cold reopens per solver. Eight
real Windows Workshop graphical/two-client checks passed. Extracted SDK examples
and the adjustable-load starter passed on both backends, including Windows
clients and Linux dedicated servers. Original client and SDK sources remain
named after byte-identical artifact comparisons. Main matrix checks use
NeoForge 21.1.231; local world/client checks use 21.1.248. Linux coverage is
server-side.

The worlds ZIP includes one combined Pinout yard, two Workshop editions and the
previously published 14,650-node benchmark save. That save has 20,637 connections,
1,050 stateful devices and 953 chunks. No new benchmark was run; 19.9 TPS with
p95≤50ms remains uncertified. Private oil-rig saves, benchmark tools and detailed
performance evidence remain local. The optional verification ZIP contains the
complete accepted public evidence graph.
