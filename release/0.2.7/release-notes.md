0.2.7 improves self-excited PG generator stability and transformer multimeter readings. API 1.0.0 and existing saves stay compatible.

- Coordinate supported PG generators' field and rotor calculations while preserving the original clutch response, including transformer, variac and carbon-pile excitation controls.
- Read assembled medium-transformer terminals with the PG multimeter while retaining unavailable readings during genuine loading or invalidation.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.231 or 21.1.248, Java 21, Create 6.0.10-280, CEE 1.1.4, Power Grid 0.6.2 and Architectury 13.0.8. CEE 1.1.3 retains compatibility support. Match server and client mod versions.
