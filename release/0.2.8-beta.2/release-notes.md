0.2.8-beta.2 adds audit-driven safety corrections while preserving API 1.0.0 and the published generator timing correction.

- Restore rejected CEE state coherently, including shared alternator windings, and isolate unsupported addon endpoints before callbacks.
- Fall back safely when bounded restoration is disabled; reject invalid multimeter input without changing the previous selection.
- Guard native matrix allocation and growth on Windows/Linux, and reject duplicate entries in release-equivalence comparisons.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.265, Java 21, Create 6.0.10, CEE 1.1.4, Power Grid 0.6.2 and Architectury 13.0.11. Set PG multiTicks to 16. Match server and client mod versions.
