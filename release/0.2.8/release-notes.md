0.2.8 combines faster wire processing and restoration with circuit safety corrections and reliable motor reconnection.

- Batch wire work and remove repeated CEE restoration scans; preserve stored state, unavailable readings and native allocation safeguards.
- Restore PG's original rotor and clutch timing, including intended self-excitation oscillation under overload.
- Keep attached fans intact during motor restoration and power loss, including externally driven shafts. API 1.0.0 and saves remain compatible.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.262, Java 21, Create 6.0.10, CEE 1.1.4, Power Grid 0.6.2 and Architectury 13.0.11. Set PG multiTicks to 16. Match server and client mod versions.
