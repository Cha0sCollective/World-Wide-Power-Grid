WWPG 0.2.12 restores shocks from live bare CEE wires and fixes voltage readings on isolated CEE transformer windings.

- Live bare CEE wires can shock entities again, and electrical readings recover when contact changes. Insulation and dielectric protection still apply.
- Isolated CEE transformer windings match stock node-to-ground readings. Voltage across each winding stays the same, and physical grounding still takes priority.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.262, Java 21, Create 6.0.10, CEE 1.1.4, Power Grid 0.6.2 and Architectury 13.0.12. Set PG multiTicks to 16. Match server and client mod versions.
