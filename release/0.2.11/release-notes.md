WWPG 0.2.11 fixes a factory-light wiring crash and keeps mixed CEE wires attached as Sable builds move.

- Worlds can load with an existing copper wire joining two connectors on the same factory-light terminal. New links to the same terminal are rejected.
- CEE wires attached to Power Grid and Power Dock terminals stay visible and selectable on moving Sable builds.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.262, Java 21, Create 6.0.10, CEE 1.1.4, Power Grid 0.6.2 and Architectury 13.0.12. Set PG multiTicks to 16. Match server and client mod versions.
