Updated experimental alpha for CEE 1.2.0 build 132, based on WWPG 0.2.12. All 286 full headless jobs passed; graphical acceptance has not been run for this build.

- Silences Power Grid's zero-resistance warning for WWPG's intentional transformer couplings; electrical behavior is unchanged.
- Retains the CEE electrocution, stable contact-reading and stock transformer-voltage fixes, plus earlier wire preview and moving-sublevel wiring fixes.
- Includes fresh headless-tested example worlds and the developer SDK.

## Install

Use Minecraft 1.21.1, Java 21, NeoForge 21.1.262, Create 6.0.10, CEE 1.21.1-1.2.0-132, Power Grid 0.6.2 and Architectury 13.0.12. Replace WWPG on client and server. Set PG multiTicks to 16. Test a copy of your world.
