Out-of-band alpha for CEE 1.2.0 build 132. This is an experimental testing release; WWPG 0.2.10 remains the stable release. Full acceptance has not been completed for this exact alpha.

- Prepares WWPG's electrical integration for CEE 1.2.
- Fixes CEE wire-tool preview crashes over Power Grid and Power Dock terminals.
- Corrects mixed-wire endpoint positions on Sable sublevels, including movement interpolation.

## Install

Use Minecraft 1.21.1, Java 21, NeoForge 21.1.262, Create 6.0.10, CEE 1.21.1-1.2.0-132, Power Grid 0.6.2 and Architectury 13.0.12. Replace your WWPG jar; match client/server versions. Set PG multiTicks to 16. Test a copy of your world. Focused checks and client loading passed; in-world sublevel visuals still need confirmation.
