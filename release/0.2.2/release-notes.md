0.2.2 brings together alpha.1 and beta.2–beta.5. API 1.0.0 and saves stay compatible. The 14,650-node 20 TPS goal and tiny capacitor-pin targeting remain open.

- Faster loading and electrical bookkeeping: iterative wire tracing, batched network/matrix updates, grouped addon preparation and leaner terminal, wire-power and result processing.
- Safer restoration: repair unload/regrouping and batching ownership; reject invalid solver results, retain stored energy/history, stabilize contactors, fix handheld readings and keep buzzer audio client-side.
- Better tools and materials: CEE terminal highlights, fixed Workshop spawn, combined Pinout yard, addon starter/SDK guides and separately requested headless/graphical checks.

## Install

Use Minecraft 1.21.1, NeoForge 21.1.231 or 21.1.248, Java 21, Create 6.0.10-280, CEE 1.1.3, Power Grid 0.6.2 and Architectury 13.0.8. Match server and client mod versions.
