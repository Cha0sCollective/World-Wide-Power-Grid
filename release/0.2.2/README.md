# WWPG 0.2.2

[Stable downloads](https://github.com/Cha0sCollective/World-Wide-Power-Grid/releases/tag/0.2.2)
· [Verification](verification.json) · [Download hashes](download-layout.json).

This stable release promotes 0.2.2-beta.5. Every runtime jar entry is identical
except its declared mod version. API 1.0.0, native libraries, electrical settings,
equations, saved data and all sixteen substeps remain unchanged.

The cumulative notes cover alpha.1 and the published beta.2–beta.5 sequence:
iterative wire tracing, loading/matrix batching, leaner preparation and results,
addon grouping, restoration and stored-state preservation, unload/regrouping,
guarded numerical rejection, handheld meters, contactors, client-side buzzer
audio, CEE terminal highlights, Workshop spawn and integrated SDK materials.

The manifest explicitly reuses beta.5's complete headless and graphical records.
The 342 headless catalog entries and 12 Windows client scenarios keep their
actual source, runtime, helper, process and world identities. Earlier failed
attempts remain failed. No full acceptance suite or performance benchmark was
rerun for promotion. Focused release checks verify the version-only jar change,
unchanged SDK inputs and native save bytes, notes, hashes and grouped downloads.

The three playable archives change only their top-level release/jar labels and
literal README version text. Native inventories, blocks, wires, stored energy,
spawn rules and embedded original observations are untouched. The original
14,650-node benchmark is included separately, with its labels updated and all
native save bytes preserved. It is not certified for 20 TPS.

Tiny capacitor-pin targeting, the large Java factorization stall and large-yard
speed remain separate unresolved limits. The retained Workshop startup
diagnostics remain visible. Private worlds, benchmark tools and detailed
performance results stay local. Previous releases and assets are unchanged.
